Paket Lengkap

🚀 Cara Membuat User & Server Panel Sekaligus

  1. 1
    Login ke Dashboard: Masuk ke zeroixdarkmarket.web.id/dashboard menggunakan username & password dari admin.
  2. 2
    Pilih Fitur Automasi: Klik tombol "AUTOMASI DEPLOY (USER+SERVER)".
  3. 3
    Isi Spesifikasi: Masukkan data panel sesuai kebutuhan bot kamu.
  4. 4
    Eksekusi Deploy: Klik tombol "Jalankan Deploy +".
  5. 5
    Dapatkan Akses Login: Sistem otomatis menerbitkan Struk Transaksi (tombol kanan) & Data Login Panel Pterodactyl (tombol kiri).
  6. 6
    Atur Masa Aktif: Di tabel "Basis Data Pengguna", cari username tadi lalu klik "Konfigurasi" untuk atur tanggal expired dalam hitungan hari.
  7. 7
    Selesai! Panel otomatis aktif dan siap digunakan.
Server Tambahan

➕ Cara Menambah Server di Username yang Sudah Ada

  1. 1
    Masuk Dashboard: Akses halaman dashboard kamu.
  2. 2
    Pilih Alokasi Tambahan: Klik menu "ALOKASI SERVER TAMBAHAN".
  3. 3
    Pilih User Target: Pilih username pelanggan yang sudah pernah terdaftar.
  4. 4
    Set Atur Resource: Tentukan Nama Server, RAM, CPU, dan Disk (Penyimpanan) sesuai paket pesanan.
  5. 5
    Eksekusi: Klik tombol "Jalankan Deploy +".
  6. 6
    Selesai! Struk otomatis muncul di layar & server tambahan resmi aktif.
